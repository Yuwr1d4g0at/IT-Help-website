Windows 10 No Longer Gets Security Updates

Microsoft ended free support for Windows 10 in October 2025. It still runs fine day to day, but any security holes found in it from now on stay open, unless you're enrolled in the paid Extended Security Updates program. If you're still on it, it's worth knowing what your real options are.
