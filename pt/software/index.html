Software que Recomendo

Escolhas de confiança, não uma lista patrocinada.

0 selecionados Marque o que quiser na lista abaixo e receba um único script que instala tudo. Corre em winget, já incluído no Windows 10/11, e não hospedo nem agrupo nada por conta própria. No Windows 7 / 8.1 o script usa o Chocolatey em vez do winget, e fixa cada programa na última versão que ainda funciona. Os programas a cinzento já não têm versão compatível, por isso ficam de fora. No Mac o script usa o Homebrew, o gestor de pacotes gratuito que a maioria dos técnicos de Mac usa, e instala-o primeiro se for preciso. Os programas a cinzento são só para Windows; aparecem algumas alternativas para Mac no lugar deles.

Atenção: o Windows 7 e 8.1 já não recebem atualizações de segurança, e a maioria destes programas também fica presa em versões antigas. Serve para um PC sem internet ou guardado para um programa antigo, mas não para o banco nem para o email. A solução a sério é atualizar: veja se o seu PC aguenta o Windows 11, ou fale comigo.

Antes de correr o script (só uma vez)

  1. Confirme que o Windows 7 tem o Service Pack 1 e todas as atualizações que o Windows Update ainda oferece. Para ver, abra o Iniciar, clique com o botão direito em Computador e escolha Propriedades.
  2. Instale o .NET Framework 4.8 (o instalador offline da Microsoft) e reinicie.
  3. Só no Windows 7: instale o Windows Management Framework 5.1 (ou a versão de 32 bits). Extraia o zip, faça duplo clique no ficheiro .msu e reinicie. Passos da Microsoft se tiver dúvidas.

Sem isto, o Windows 7 não consegue fazer a ligação segura de que o Chocolatey precisa. O script verifica estes passos primeiro e diz-lhe o que falta, em vez de falhar a meio.

Antes de correr o script

  1. Use uma conta de administrador (normalmente a que foi criada quando o Mac foi configurado). O Homebrew pede a palavra-passe uma vez. Não aparece nada no ecrã enquanto escreve, e isso é normal.
  2. Se o Mac ainda não tiver as Command Line Tools da Apple, o Homebrew descarrega-as primeiro. Essa parte pode demorar 5 a 15 minutos.
  3. Alguns programas precisam de uma versão recente do macOS. Num Mac mais antigo esses param com uma mensagem, e os restantes instalam na mesma.

Os programas vêm da página oficial de cada programador, e o próprio Homebrew é gratuito e open-source. Um programa que já tenha instalado à mão recebe uma mensagem a dizer que já existe e é saltado.


          

            Descarregar instalar-selecionados.batDescarregar instalar-selecionados-win7.batDescarregar instalar-selecionados-mac.sh
            
          

          
Precisa do winget (já incluído no Windows 10 2018+ e Windows 11). Faça duplo clique no ficheiro, e escolha "Mais informações → Executar mesmo assim" se o Windows SmartScreen perguntar. É normal para qualquer script não assinado, como um que escrevesse você mesmo, e instala tudo sem mais avisos.

          
Clique com o botão direito no ficheiro e escolha "Executar como administrador". Verifica os passos acima, instala o Chocolatey (um gestor de pacotes gratuito e open-source) se for preciso, e depois os seus programas, cada um fixo na versão para Windows 7. Os maiores, como o LibreOffice, demoram um bocado.

          
Abra o Terminal (carregue em ⌘ Cmd + Espaço, escreva Terminal e carregue em Enter). Escreva bash e um espaço, arraste o ficheiro descarregado para a janela do Terminal e carregue em Enter. Não cole o script diretamente: a instalação do Homebrew faz perguntas e ia engolir as linhas seguintes.
