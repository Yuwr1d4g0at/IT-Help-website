Atalhos de Teclado do Windows

Os atalhos que realmente poupam tempo no dia a dia, não a lista completa que ninguém decora. Imprima e guarde perto da secretária.

Básicos da Tecla Windows

  • Win: Abre ou fecha o menu Iniciar.
  • Win + D: Mostra ou esconde o ambiente de trabalho.
  • Win + L: Bloqueia o computador.
  • Win + Tab: Abre a Vista de Tarefas, para ver e alternar entre todas as janelas abertas.

Gestão de Janelas

  • Win + Seta Esquerda/Direita: Encaixa a janela atual numa metade do ecrã.
  • Win + Seta Cima/Baixo: Maximiza ou minimiza a janela atual.
  • Alt + Tab: Alterna entre janelas abertas, mantido premido para escolher uma.

Texto e Edição

  • Ctrl + C / Ctrl + V: Copiar e colar.
  • Ctrl + Z / Ctrl + Y: Desfazer e refazer.
  • Ctrl + F: Procurar texto na página ou no documento.
  • Ctrl + A: Selecionar tudo.

Atalhos do Navegador

  • Ctrl + T: Abrir um novo separador.
  • Ctrl + Shift + T: Reabrir o último separador que fechou.
  • Ctrl + L: Ir diretamente para a barra de endereço.

Capturas de Ecrã

  • Win + Shift + S: Capturar parte do ecrã, pronto para colar em qualquer lado.
  • Win + PrtScn: Guardar uma captura completa do ecrã diretamente num ficheiro.
