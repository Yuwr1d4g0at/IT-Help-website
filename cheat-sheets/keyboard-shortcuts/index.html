Windows Keyboard Shortcuts

The shortcuts that actually save time day to day, not the full list nobody memorizes. Print this and keep it near the desk.

Windows Key Basics

  • Win: Open or close the Start menu.
  • Win + D: Show or hide the desktop.
  • Win + L: Lock your computer.
  • Win + Tab: Open Task View, to see and switch between all open windows.

Window Management

  • Win + Left/Right Arrow: Snap the current window to one half of the screen.
  • Win + Up/Down Arrow: Maximize or minimize the current window.
  • Alt + Tab: Switch between open windows, held down to pick one.

Text & Editing

  • Ctrl + C / Ctrl + V: Copy and paste.
  • Ctrl + Z / Ctrl + Y: Undo and redo.
  • Ctrl + F: Find text on the page or in the document.
  • Ctrl + A: Select everything.

Browser Shortcuts

  • Ctrl + T: Open a new tab.
  • Ctrl + Shift + T: Reopen the last tab you closed.
  • Ctrl + L: Jump straight to the address bar.

Screenshots

  • Win + Shift + S: Capture part of the screen, ready to paste anywhere.
  • Win + PrtScn: Save a full screenshot straight to a file.
