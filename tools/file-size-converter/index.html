File Size Converter

Decimal is what's printed on a drive's box and what phone or cloud storage plans usually mean. Binary is what Windows shows in File Explorer, which is why a "512 GB" drive shows up there as roughly 477 GB: same bytes, different math, not a missing 35 GB.
