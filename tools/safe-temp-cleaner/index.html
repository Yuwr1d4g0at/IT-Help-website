Safe Temp Cleaner

A small, free PowerShell script for Windows 10 and 11. It shows you which old temporary files can go and how much space they take, and only deletes them after you say yes.

Download the Safe Temp Cleaner

SHA-256: 2e9835b7baa3297352ae2e2fd48f257316b4de695ca8c49d34274b2b3c94b196

What it does

  • Preview first, always. By default it only lists what it would remove and the total size. Nothing is deleted until you type Y and press Enter. Anything else quits without touching a thing.
  • Your temp folder (%TEMP%): only files that haven't changed in the last 24 hours.
  • The Windows temp folder (C:\Windows\Temp): same rule, but only when you run it as administrator. Otherwise it's skipped, with a note saying so.
  • The Windows Update download cache: only if you run it as administrator and ask for it with -IncludeUpdateCache. It stops the Windows Update and BITS services first, empties C:\Windows\SoftwareDistribution\Download, and starts the services again afterwards, even if something goes wrong.
  • Files in use are skipped and counted, never forced.

What it never does

  • It never touches the Recycle Bin, your Downloads, Documents, Desktop or other personal folders.
  • It never touches browser profiles, browser caches or saved passwords.
  • It never touches the registry.
  • It makes no internet connections and sends nothing anywhere.
  • It never tries to give itself administrator rights. If you want the admin-only parts, you choose to run it as administrator.

How to run it

  1. Download the file and save it somewhere easy to find, like your Desktop.
  2. If you like, open it in Notepad first and read it. It's plain text, with comments explaining each part.
  3. Right-click the file and choose Run with PowerShell. You'll see the preview, then the question.

To include C:\Windows\Temp, open PowerShell as administrator (right-click the Start button, then Terminal (Admin) or Windows PowerShell (Admin)), go to the folder where you saved it and run:

powershell -ExecutionPolicy Bypass -File .\yuwri-safe-temp-cleaner.ps1

-ExecutionPolicy Bypass only applies to that one run. It doesn't change any setting on your computer. Add -IncludeUpdateCache at the end to also clear the Windows Update download cache, or -ShowAll to list every file in the preview instead of just the largest ones.

Check that the file is the original

Before running a script from the internet, it's good practice to check it hasn't been changed along the way. In PowerShell, in the folder where you saved it, run:

Get-FileHash .\yuwri-safe-temp-cleaner.ps1 -Algorithm SHA256

The result should match the SHA-256 shown above exactly. If it doesn't, don't run it, and let me know.

Provided as-is

The script is free and provided as-is, without any warranty. I've kept it deliberately cautious, but you run it at your own risk. If you have important files, make sure they're backed up before any kind of clean-up.
