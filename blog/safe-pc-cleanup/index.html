Cleaning Up Your PC Safely: What to Delete and What to Leave Alone

Home / Tips / Cleaning Up Your PC Safely
October 2026

When a computer runs out of space, the temptation is to start deleting whatever looks big or unfamiliar. That's how people end up with programs that won't open or a Windows that won't start. The good news: the things that are actually safe to clean are easy to get to, and Windows already has most of the tools built in. Here's what I clean on a client's PC, and what I leave alone.

Before anything else: if there are files on the computer you'd be upset to lose, make sure they're copied somewhere else first. This guide to backups keeps it simple.

1. Let Windows do the heavy lifting: Storage Sense and Disk Cleanup

Go to Settings > System > Storage. Windows shows what's using the space and offers Cleanup recommendations. Turn on Storage Sense too, and Windows will clear out temporary files on its own from then on.

The older Disk Cleanup tool is still there and still useful. Type "Disk Cleanup" in the Start menu, pick the C: drive, then click Clean up system files. That second step is the important one: it unlocks the bigger items, like leftover Windows Update files. Almost everything it offers is safe to tick. Two boxes deserve a second look: Downloads, because it really does empty your Downloads folder, and Previous Windows installation(s), because after a big upgrade it removes the option to go back to the old version.

2. Temporary files

Programs leave temporary files behind all the time, in two main places: your own temp folder (press Windows + R, type %TEMP% and press Enter) and C:\Windows\Temp. Deleting old files from these folders is safe. Some files will be in use and Windows will refuse to delete them. That's fine: tick "Do this for all current items" and choose Skip. A restart frees most of them.

If you'd rather not do this by hand, I wrote a small free tool for it, the Safe Temp Cleaner. It shows you what it would remove first, and only deletes after you say yes. More on it below.

3. Browser caches, from inside the browser

Browsers keep a cache of images and pages to load sites faster. It can grow to a few gigabytes, and clearing it is safe. Do it from the browser's own settings, not by deleting folders: in Chrome, Edge and Firefox, press Ctrl + Shift + Delete, choose Cached images and files and clear it. Leave passwords and cookies unticked unless you know you want them gone, otherwise you'll be logged out of everything.

4. Old Windows Update files

Windows keeps update files around after installing them. In Disk Cleanup (after clicking "Clean up system files"), tick Windows Update Cleanup and Delivery Optimization Files: that's the safe way to clear what's no longer needed.

The downloads themselves sit in C:\Windows\SoftwareDistribution\Download. That folder can be emptied, but only with the Windows Update service stopped, never while it's working. Don't delete it by hand. My cleaner (below) can do it properly if you ask it to: it stops the service, clears the folder and starts the service again.

5. Duplicate files

Photos copied from a phone three times, the same video in Downloads and on the Desktop: duplicates add up. There are tools for this, but you can also check with PowerShell, which is already on your PC. This snippet only reports duplicates in your Pictures folder. It doesn't delete, move or change anything:

$folder = "$env:USERPROFILE\Pictures"
Get-ChildItem -Path $folder -File -Recurse -ErrorAction SilentlyContinue |
  Get-FileHash -Algorithm SHA256 |
  Group-Object -Property Hash |
  Where-Object Count -gt 1 |
  ForEach-Object { "--- $($_.Count) identical files ---"; $_.Group.Path }

Open PowerShell from the Start menu, paste it in and press Enter. Change the first line to check a different folder. Each group it prints is a set of files with exactly the same content. Then look through them yourself and decide which copy to keep. On a big folder it can take a few minutes.

6. Broken shortcuts

After uninstalling programs, you often end up with shortcuts on the Desktop or in the Start menu that point to nothing. Clicking one gives an error, or Windows asks if you want to delete it. Deleting a shortcut is always safe: it's just a link, not the program itself.

7. Programs you don't use

Go to Settings > Apps > Installed apps and sort by size. Trial software that came with the computer, games nobody plays, three different PDF readers: uninstall them from here (never by deleting their folder). If you don't recognise a name, search for it before removing it. Things with the name of your computer's brand, or words like "driver", "audio" or "chipset", are usually best left alone.

What to leave alone

  • The Windows folder, and especially WinSxS and System32. They look huge, but Windows needs them. Disk Cleanup already trims what can safely go.
  • Program Files and AppData. Removing folders here breaks programs. Uninstall properly instead.
  • pagefile.sys and hiberfil.sys. Windows manages these itself.
  • Anything you don't recognise just because it's big. When in doubt, ask first.

Why I don't use registry cleaners

Registry cleaners promise a faster PC by "fixing errors" in the registry, the database where Windows keeps its settings. I don't use them, and I don't recommend them:

  • Microsoft doesn't support them. Microsoft's own guidance is that it doesn't support registry cleaners, and that problems they cause may not be fixable without reinstalling Windows.
  • There's little or no speed to gain. A few thousand leftover entries in a database that size make no noticeable difference. The "errors" they count are mostly harmless.
  • They can break things. Remove the wrong entry and files stop opening with the right program, an app won't start, or an update fails. The risk is real and the reward is close to zero.
